# Evidence-driven roadmap

## v0.1
- SQLite project state
- ideas and PDF import
- OpenAlex retrieval
- OpenAI + Anthropic provider adapters
- local cost ledger and monthly budget

## Gate before v0.2
Run at least 3 old ideas with known outcomes, 1 false/flawed conjecture, and 2 current ideas. Record whether the tool materially changed your understanding or next action.
